00교육과정 개요

이 교재는 AI 모델을 사용해 답변하는 단계에서 외부 도구를 호출하고 작업 결과를 검증하는 엔지니어링 에이전트까지 점진적으로 확장합니다. 각 장의 코드는 개별 실행 단위로 구성되고, 연결 가능한 구성요소를 누적해 제10장의 통합 시스템으로 발전시킵니다.

02학습·실습·배포 안내

구분진행 기준
기본 환경Ubuntu + Python + VS Code + Git / GitHub
실습 순서핵심 개념 → 구조도 → 설치·설정 → 코드 → 실행 확인 → 검증
프로젝트각 장은 독립 실행 가능하게 구성하고, 이후 필요한 모듈을 재사용
실행 결과교재에 표시한 예시 출력은 실제 환경에서 재확인하고, 검증되지 않은 외부 도구 동작은 성공으로 간주하지 않음
안전한 작업기존 FPGA·KiCad 프로젝트를 원본으로 보존하고, 변경·배포는 명시적인 승인 이후 수행
공개 자료토큰·실명 계정·개인 경로·내부 주소 등을 점검한 뒤 GitHub Pages 배포

각 장의 세부 목차 펼쳐보기에서 00~12절을 확인한 후 해당 장으로 이동할 수 있습니다. 장별 링크는 같은 폴더에 HTML 파일을 함께 배치할 때 동작합니다.
